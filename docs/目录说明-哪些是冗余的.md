# AI 陪伴目录说明

本说明按当前源码和启动脚本整理。完整启动方法见根目录 `README.md`。

## 哪些是程序本体

- `src/`：电脑和手机共用的后端。`account_features.py` 负责账号规则；`optional_features.py` 只在显式摄像头模式加载摄像头后端。
- `frontend-src/`：可编辑的前端源码。`src/renderer/src/desktop/` 是电脑入口，`src/renderer/src/mobile/` 是手机入口，其他组件与服务共用。
- `frontend/`：已构建、要提交到 Git 的网页。`index.html` 给普通电脑，`m.html` 给手机，`camera.html` 给摄像头模式；三个页面共用 `assets/` 和 `libs/`。
- `prompts/prompts.yaml`：全部提示词的唯一来源。
- `content/`：角色配置、头像、背景及按角色分组的表情图片。
- `live2d-models/`：Live2D 模型。`models/`：本地语音、检索和图像模型；模型不提交到 Git。
- `摄像头/`：可选功能。普通启动不导入它的后端、不显示摄像头页面、不启动 8765 代理；只有专用启动器启用。

## 哪些留在本地，不上传

`chat_history/` 和 `backups/` 是个人数据，必须保留；`models/` 是可重新获取但下载较大的本地模型，也保留。`logs/`、`cache/`、虚拟环境、`node_modules/`、编辑器文件、私钥与 `.env` 均不上传。`.gitignore` 负责排除它们，但已被 Git 跟踪的文件需要另行核对，不能只依赖忽略规则。

## 哪些可以清理

- `.DS_Store`、`__pycache__/`、空的旧目录是可再生文件或空壳，可删除。
- `frontend-src/dist/` 和 `frontend-src/out/` 是构建中间结果；删除后构建会重新生成。
- `frontend/` 是部署必需的构建产物，不应当作垃圾删除。
- `.png` 与 `.webp` 表情图片分别支持电脑与手机，不应只凭文件名相似就删除。
- `frontend-src/node_modules/` 是构建依赖；删除后修改前端时必须重新安装。

“未运行”不等于“无用”：手机页面、摄像头代码、测试与说明文档都可能只在对应场景需要。清理源码和图片前应核对引用及用户数据。Git 仓库只保存可复现程序的文件，不保存每台机器的运行状态。
