# 可移除的静态表情模块

`manifest.json` 中的 `enabled` 是总开关：

- `true`：过滤回复末尾的情绪协议，并用同名 PNG 替代 Live2D。
- `false`：完全保留原有文本、TTS 和 Live2D 行为。

删除整个 `expression/` 文件夹也会自动回到原有行为。修改开关或文件后，重启后端并刷新前端页面即可生效。

当前识别以下四种回复末尾格式：

- `当前我的情绪为：愉快`
- `当前情绪为：愉快`
- `当前情绪为愉快`
- `当前情绪我的为：愉快`

只有 `manifest.json` 中声明且对应图片存在的情绪才会触发过滤和切换。

`transition` 控制新旧图片的交叉淡化。默认使用 `160ms ease-out`；交叉淡化期间两张图片重叠显示，因此不会先淡出到空白。把 `transition.enabled` 改为 `false` 可以单独恢复瞬间切换，而不关闭整个表情模块。

设置页的“启用鼠标交互”和“启用滚轮缩放”同时适用于当前静态表情贴图。拖动位置和滚轮缩放会自动保存，并按 Live2D 模型分别记忆；切换情绪贴图时保持同一布局。
